# 🎮 Real-Time Multiplayer Guessing Game

A fun, interactive, and competitive real-time multiplayer guessing game where friends can create private rooms, join using unique room codes, draw clues, guess hidden answers, and compete to become the ultimate champion!

The game supports up to **8 players in a single room**, with a minimum of 2 players required to start. Players take turns becoming the Hint Giver while others compete to guess the correct answer within a 2-minute time limit.

## ✨ Key Features

- **Multiplayer Rooms:** Create or join rooms using unique room codes. Supports 2–8 players per room.
- **Number Guessing:** Select a secret number and provide clues such as digit count, even/odd, and number ranges.
- **Word Guessing:** Draw hidden words on a shared canvas while other players try to identify them.
- **Draw & Guess:** Enjoy creative drawing challenges with different categories and difficulty levels.
- **Live Drawing Board:** Includes pencil, eraser, colors, brush sizes, undo, and clear options.
- **Real-Time Gameplay:** Synchronize player actions, guesses, drawing strokes, and scores instantly.
- **2-Minute Timer:** Every round includes a 120-second countdown with warning alerts.
- **Smart Scoring:** Earn points based on guessing speed, accuracy, and performance.
- **Player Rotation:** Give every player a fair opportunity to become the Hint Giver.
- **Live Leaderboard:** Track scores and compete with other players.
- **Sound Effects:** Enjoy interactive audio for correct answers, wrong guesses, countdowns, game starts, and victories.
- **Background Music:** Customizable music and sound-effect volume controls.
- **Live Chat & Emojis:** Communicate and react with other players during gameplay.
- **Winner Celebration:** Enjoy animations, confetti, and final rankings.
- **Responsive Design:** Play smoothly on desktops, tablets, and mobile devices.

## 🛠️ Technology Stack

- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Backend & Database:** Supabase
- **Real-Time Communication:** Supabase Realtime
- **Game Logic:** Secure server-side validation and scoring.

## 🎯 Objective

The main objective is to guess hidden numbers and words as quickly as possible, earn maximum points, and climb the leaderboard. Players must use creativity, observation, speed, and logical thinking to win.

## 🚀 Vision

To create an exciting online multiplayer party game that brings friends together through drawing, guessing, teamwork, and friendly competition.

**Play together. Draw creatively. Guess quickly. Become the champion! 🏆**
